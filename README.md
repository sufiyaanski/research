# research

Research and a ready-made setup for making short-form motion-graphic reels with Claude Code (The Signal, Q-ROSITY).

- **Running the channels (start here if you just want to make videos):** [`START-HERE.md`](START-HERE.md) — then type `/go` in Claude Code. Studio rules: [`CLAUDE.md`](CLAUDE.md); board: [`studio/STATUS.md`](studio/STATUS.md).
- **Research summary:** [`research/00-SUMMARY.md`](research/00-SUMMARY.md): the 10 changes to make, ranked, and where everything is.
- **Copy-paste prompts and recipes:** [`research/04-PROMPTS.md`](research/04-PROMPTS.md).
- **Ready-made Claude Code + Remotion kit:** [`setup/`](setup/). Read [`setup/README.md`](setup/README.md), then `cd setup && npm install && claude`.
  - Demo reels with QA stills: `setup/episodes/signal-001-anchoring/` (The Signal) and `setup/episodes/qrosity-001-volcano/` (Q-ROSITY, 3D blocky character).
- Research files: `research/01*` (making the reels), `02` (growth), `03` (automation), `05` (all sources, verified/unverified), `transcripts/` (full video transcripts).
