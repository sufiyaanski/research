# Q-ROSITY — channel bible

> Read this AND `toolkit/HARNESS.md` (§1–4, §6) before any Q-ROSITY reel. HARNESS wins on render rules.

## 1. Audience & promise
- **Who:** 13–30 doom-scrollers who love "what if" hypotheticals and stakes, not lessons.
- **Promise:** "What if ___? We live it — one blocky guy, real consequences."
- **Feeling at the end:** "wait — what?" → rewatch (loop) or comment what they'd have done.

## 2. Format
- Vertical 1080×1920 @ 30, **30–60 s** (IG/YT 30–45 s; TikTok 61–70 s "extended episode" when chasing Creator Rewards).
- Escalation grammar: **me → my street → my city → the world**, each beat a bigger consequence, then a twist/loop line.
- Camera: push-in on the hook; 10–20° orbit on a reveal; low angle on the consequence; ≤ 7-frame shake on impacts; cut every 1.5–3 s.
- Frame 0: "WHAT IF" title over the scene (never a black card). Captions per HARNESS §1.3.

## 3. Series (log each episode's scenario / setting / outcome / twist in `ideas.md` → "Used")
| Series | What |
|---|---|
| **What If Day N** | numbered; the same character carries consequences forward (inventory, injuries, a running goal) — a "series following characters across episodes" (allowed), NOT "same situation, same outcome" (demonetised) |
| **Survive X Seconds** | a visible timer (the what-if countdown format in `toolkit/examples/whatif-countdown/`) — rotate outcomes: survive / fail / twist |
| **You Chose This** | Saturday episode built from the best comment answer |
| **World Flip** | one physical rule changes (gravity ×2, no friction, Earth stops spinning) — science-flavoured drama, consequences first |

## 4. Hook styles
"What if ___ for 10 seconds?" · cold POV ("You wake up and the Moon is gone") · stakes number ("8 billion people, 10 seconds") · the impossible image on frame 0.

## 5. Look (HARNESS §6)
- Detailed, lit 3D sets built in code (street, room, city, crowd, landscape): layered depth, practical lights, fog. Each beat changes the set or the scale.
- Overlay palette: text #FFF6EC, accent #FFD23F, caption plate #120A10 @ 82 %, night #0A0D16. Display Rubik 900, body Nunito 800. Hard drop shadows, never glow.
- Character: the blocky person, `DEFAULT_PALETTE` (purple hoodie #6A33FF, yellow "?" emblem). POV = his hands/view; reactions = mood takes, never snaps.

## 6. Banned
Minecraft/Roblox names, logos, block textures or sounds · gore · real disasters with real victims as entertainment · "follow for part 2" (say "Part 2 is on my page") · the same outcome twice in a row · science-lecture tone.

## 7. Policy: vary on purpose (YouTube "inauthentic content")
Before writing: read the last 10 rows of "Used" in `ideas.md`. **No scenario type, setting AND outcome may repeat within 10 episodes; no outcome more than twice in a row.** `/idea` scores novelty against this list. Monthly: scroll the last 10 uploads — if a stranger would say "same video, different numbers", vary harder.

## 8. Facts
Hypotheticals are fiction, but any real number used to raise the stakes ("8 billion people") gets a `facts.md` line with a URL.

## 9. CTA rules
No gates. On screen at most 1 in 3: *"What would YOU have done differently?"* Caption: *"Best answer becomes Saturday's episode."* Never "comment YES", "like if…".

## 10. Cadence
| | Start (weeks 1–4) | Scale |
|---|---|---|
| Public reels (IG + TikTok + YT) | **3 / week** (Tue, Thu, Sat — Sat = "You Chose This") | 5 / week |
| Shorts cut from the long-form (YouTube only) | 2 per long-form episode | 3 |
| IG Trial Reels (≥ 1,000 followers) | 0 | 2 hook variants per public reel |
