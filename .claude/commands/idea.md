# /idea — capture + score

The idea: **$ARGUMENTS**

1. Read the bibles in `studio/channels/*/bible.md` (skip `status: template` ones except to note the slot is free) and the `## Used` table + backlog of each candidate channel's `ideas.md`.
2. Decide which channel it fits (audience, promise, format, banned list). Say why in one line. If it fits two, pick the one where it scores higher and say so.
3. If it fits **no** live channel: say so, and propose either (a) reshaping it to fit one, or (b) running `/new-channel` with it as the seed (and which of the channel-3 candidates it resembles). Do not create a channel here.
4. Write the idea as **one line a stranger understands**, plus 2 alternative hooks (different hook styles from the bible).
5. Score it with the rubric in that `ideas.md` (Hook, Novelty vs the last 10 Used rows — for Q-ROSITY compare scenario/setting/outcome/twist —, Cost, Fact safety; Score = 2H + 2N + C + F). Be strict; a 5 must be earned. Note what source the facts would need.
6. Append the row to the backlog table (next id: S#, Q#, L#, C#) with status `scored` (or `idea` if < 18), and show the row to the user.
7. If it scores ≥ 22, offer to put it on the calendar (don't do it unless they say yes).
